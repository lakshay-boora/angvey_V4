# Contributing to Angvey V4

Thank you for your interest in contributing to Angvey V4!  
We welcome contributions of all kinds — code, documentation, bug reports, feature ideas, and more.

## How to Contribute

1. **Fork** the repository
2. Create a new branch for your change:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. Make your changes
4. Commit with a clear message:
   ```bash
   git commit -m "Add: short description of your change"
   ```
5. Push to your fork and open a **Pull Request** against the `main` branch

## Guidelines

- Keep changes focused and small when possible
- Write clear commit messages
- Update documentation if your change affects usage
- For large features or architectural changes, please open an issue first to discuss
- Be respectful and constructive in all interactions

## Code Style

- Follow standard Go conventions (`gofmt`, `golint`, etc.)
- Prefer clarity over cleverness
- Add comments for non-obvious logic

## Reporting Bugs

Please open a GitHub Issue and include:
- Steps to reproduce
- Expected vs actual behavior
- Environment details (OS, Go version, etc.)

## Feature Requests

Open an Issue describing the problem you want to solve and any ideas you have for the solution.
